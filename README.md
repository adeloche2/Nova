# Nova Programming Language

Nova is an experimental general-purpose language for Windows, implemented in Python with its own bytecode compiler and virtual machine.

## Project snapshot

The complete Nova v0.1.0 source bundle is available in [`Nova-0.1.0.zip`](Nova-0.1.0.zip). Extract the archive to access the source package, examples, tests, and technical documentation.

## Design
- Dynamic typing
- Indentation-based blocks
- Nova bytecode virtual machine
- Classes, instances, attributes, and methods in the first milestone
- Windows-first CLI

See the archive's README.md for installation and usage instructions. This is an early experimental milestone; see `docs/` for current limitations and architecture.
